# PowerbiProject
The proposed system is an interactive Amazon Sales Analysis Dashboard developed using Microsoft Power BI.
    The solution provides:
Real-time visualization of YTD Sales, QTD Sales, Products Sold, and Reviews
Monthly and weekly sales trend analysis
Category-wise and product-wise sales insights
Top 5 products based on sales and customer reviews
User-friendly filters for Product Category and Quarter
This dashboard helps stakeholders make data-driven business decisions quickly and efficiently.
